Connect your tools

Python · PyIceberg

Install pyiceberg[pyarrow]. Set the credentials below in your client environment.

{{ config.public }}/api/catalog
import os
from pyiceberg.catalog import load_catalog

catalog = load_catalog(
    "{{ config.name }}",
    type="rest",
    uri="{{ config.public }}/api/catalog",
    warehouse="{{ config.name }}",
    credential=os.environ["POLARIS_CLIENT_ID"] + ":" + os.environ["POLARIS_CLIENT_SECRET"],
    scope="PRINCIPAL_ROLE:ALL",
    **{
        "header.X-Iceberg-Access-Delegation": "",
        "oauth2-server-uri": "{{ config.public }}/api/catalog/v1/oauth/tokens",
        "s3.endpoint": "{{ config.endpoint }}",
        "s3.region": "{{ config.region }}",
        "s3.access-key-id": os.environ["AWS_ACCESS_KEY_ID"],
        "s3.secret-access-key": os.environ["AWS_SECRET_ACCESS_KEY"],
        "s3.force-virtual-addressing": "{{ 'false' if config.path_style else 'true' }}",
    },
)
catalog.create_namespace_if_not_exists("demo")
print(catalog.list_namespaces())

This template uses direct S3 credentials. Configure them in each client; the catalog does not vend temporary storage credentials. Use the bootstrap account to get started, then create dedicated principals for applications.
